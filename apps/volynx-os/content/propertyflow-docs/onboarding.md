# Property Flow hosted onboarding

## The simple path

The hosted Property Flow workspace is the default product. You do not need to install Node.js, edit a JSON file, hire a developer or give VOLYNX access to your current website.

After a successful purchase:

1. **Your account is confirmed.** Stripe confirms the payment and your VOLYNX account receives the entitlement.
2. **Your workspace is created.** The dashboard, organization, site shell and tenant-isolated data space are provisioned automatically.
3. **Your first address is reserved.** You receive a free address such as `your-brand.volynx.world`.
4. **You complete the guided setup.** Add your logo, brand name, colors, contact details and first properties.
5. **You choose a template.** Only templates included in your tier can be activated. Changing a template does not change properties, photos or copy.
6. **You publish.** The public site uses the selected brand, template and published properties.

## If you do not have a domain yet

Choose **Create a VOLYNX address** in the publication area. You can launch immediately with the reserved subdomain and connect a custom domain later.

## If you already have a domain

Choose **Use my own domain**. The dashboard shows the exact DNS record to add and verifies the connection before marking the site ready. We do not ask for your registrar password.

## If you already have a website

Your existing website remains untouched. The safest path is a link or subdomain pointing to Property Flow. An embedded catalogue or a new route inside the existing site is optional and depends on what that site supports; it is never assumed to work without access to its hosting or code.

## What the ZIP is for

The protected ZIP is an optional, complete standalone static site with local JSON content, local images and the templates licensed for your tier. It is not required for the hosted workspace, dashboard, template switching or publication flow. Use it when your team wants source-level control or a separate static deployment; it does not synchronize with the hosted workspace.
